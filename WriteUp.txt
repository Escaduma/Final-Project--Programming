Write Up

From the start, I knew exactly what I wanted, so I began with the basics: creating the interface and Googling the features of the different options I was considering, as well as how I could design it my own way. Once I had the general idea figured out, I started creating the functions, which were a bit complicated. I created the first two based on projects I had worked on throughout the class. Then, for the remaining ones, I got help from Claude, since I felt those were a bit more complicated to make. I’d create the function as a draft, send it to Claude to see what could be improved, and with the AI’s help, I managed to finish my functions, and each one worked just as I wanted. When I thought everything was working well, I showed my work to a friend and got some more ideas that I liked, so I made some changes to the text, because it was too small, and I also made the main window bigger. That’s how I arrived at the final result. I created images in Canva and figured out how to add them, only to realize that I needed to be more organized. So I put the photos and the Excel document in a single folder to finally finish everything.

The biggest challenge I faced was creating the functions and importing them where they needed to go, because with so much code, I sometimes lost track of where each one was located. On top of that, some of them required features I hadn’t used before, so I had to look them up and ask how they worked.

What I learned was how to significantly improve Tkinter’s graphical interfaces, as well as other ways to use `if` statements more simply to avoid making the code so long, among other tools included in Tkinter that we didn’t cover in class.
